# Create a task plan

Use this skill when asked to plan how to execute a task. Use the /hand-over skill to write the plan.

Ground the plan in desired target behaviour. Lay out the goal, constraints, implementation steps, dependencies and observable verification; call out unknowns rather than guessing. Include load-bearing source and test templates for key data shapes, interfaces, execution flow and assertions; give code that can be as detailed and complete as possible short of details that can only be discovered during implementation. Keep environment guidance portable and minimal: avoid incidental environment details that may change, and have the implementer verify current commands and prerequisites. Do not implement the task while planning.
