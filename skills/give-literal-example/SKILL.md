# Give a literal example

Use this skill when the user has requested an explanation of something using a literal, concrete example instead of an abstract, general description.

This skill may pair well with the /write-step-by-step-explanation skill.

## Principles

**Use a relevant, relatable example.** When giving the example, use an example that the user can relate to, e.g. a case with realistic values, shapes and structure that may genuinely occur for the user in some situation.

**Enumerate several examples if generality gets lost.** Concreteness may lose generality; if so, enumerate several examples in order to illustrate a fuller range of behaviour or cases, so that the reader can infer the general principle from the specific examples.
