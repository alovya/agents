# Explain inside out

Use this skill to explain a system from the inside out.

This skill pairs well with the /give-literal-example skill.

## Principles

**Start at the innermost layer.** Describe the smallest, most frequently exercised unit first, such as a single step, call or object, and what it assumes already exists. This is the part the whole system exists to serve, so the reader learns the purpose before any machinery.

**Introduce each outer layer as the answer to what the inner one assumed.** For each enclosing layer, say what it creates when it starts, what happens inside it, and what it destroys when it ends. The reader then never holds a step in memory without knowing what it is for, and every lifetime is visibly nested inside the next.

**Finish with one nested timeline, then locate the change on it.** Show all the layers as a single indented timeline; if a change is being explained, show the same timeline again with the moved or changed step marked.
